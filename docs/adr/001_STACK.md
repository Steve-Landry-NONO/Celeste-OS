# Choix de stack CELESTE OS

ID ADR-001 · 2 octobre 2026 · Statut proposé

Next.js et Expo en TypeScript avec Supabase forment le choix de travail. Le domaine, les contrats, le client et les tokens sont partagés, les composants web et natifs restent séparés. Le besoin est un web lisible pour le pilotage et un mobile rapide, avec autorisations et finance communes.

Une app Expo universelle est une alternative à tester brièvement sur upload privé, historique de documents, accessibilité et déploiement. La décision définitive intervient avant scaffold. Le coût, les accès, la distribution native et les versions compatibles devront être vérifiés. Une meilleure option démontrée peut remplacer ce choix par une nouvelle ADR sans modifier les exigences produit.
