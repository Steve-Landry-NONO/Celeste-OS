# Sources et versions documentaires de CELESTE OS

ID ADR-003 · 2 octobre 2026 · Statut proposé

Une identité de document possède des versions figées, approuvées sur une empreinte et une seule référence publiée courante. Les documents techniques sont édités dans GitHub puis référencés par commit dans CELESTE OS. Les documents métier sont édités ou déposés dans CELESTE OS et exportables avec provenance.

Une synchronisation libre bidirectionnelle est différée car elle nécessiterait une règle de conflit et pourrait valider un contenu différent de celui revu. L’instantané natif est proposé au pilote, les fournisseurs externes restant remplaçables. Les octets et métadonnées sont sauvegardés ensemble.
